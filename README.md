## 📐 System Architecture & Logic Flow
How the system flows and operates:
1. User signs in via Google or continues as a Guest.
2. The system redirects the user to the Home Page.
3. User completes practice sessions and activities.
4. Progress data is saved and displayed on the leaderboard.
5. Additional content, such as 3D Objects, unlocks as the user gains XP.
